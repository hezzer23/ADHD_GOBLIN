# ADHD_GOBLIN — Style Exploration Moodboard

Open `index.html` in a browser. Every moodboard tile and source card links to the original project. Technical entries include direct documentation, demo and GitHub links where available.

## Files

- `index.html` — interactive moodboard
- `sources.json` — editable source library and TL;DR notes
- `assets/` — compressed monochrome/dither reference thumbnails

## Direction

Dark base `#0d0f14`; achromatic UI; color limited to organic node signals. Display serif + monospaced body. No glassmorphism, uniform radii, corporate gradients, glow or blur.

The included thumbnails are low-resolution, processed studies for moodboard/reference use. Each one is attributed and linked back to its source.
