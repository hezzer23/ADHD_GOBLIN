8 directions

Nu sunt opt stiluri separate. Sunt opt sisteme de reguli care trebuie combinate într-o singură gramatică.

01

Occult machine

Knowledge base-ul arată ca un manual tehnic găsit într-o arhivă suspectă. Gravura nu e decor; este probă, mascotă, diagramă și eroare de imprimare.

USEDidone mare, captions mono, numerotare, margini de planșă.
MUTATEDither agresiv, crops incomode, annotations și defecte de print.
NEVERTarot kitsch, rune fără sens sau „AI mysticism” generic.
02

Dither as material

Dither-ul descrie calitatea memoriei și a atenției: clar, murdar, pierdut, recuperat. Nu este un filtru global aplicat la final.

USEFloyd–Steinberg pentru organic; Bayer pentru motion stabil; Atkinson pentru archival crisp.
MUTATEIntensitatea devine semantică: confidence, age, focus, decay.
NEVERText funcțional dithered sau CRT maximalist cu bloom.
03

Living graph

Nodurile nu sunt cercuri. Sunt membrane deformabile cu identitate, masă, tensiune și o relație fizică vizibilă cu celelalte idei.

FORMMetaball / contour noise / asymmetry per node.
LINKTendrils care se tensionează, se ramifică și pulsează.
DECAYIdeile uitate pierd contrast, masă și legături — nu primesc un badge „stale”.
04

Audio organism

Sunetul nu colorează vizualul. Îi schimbă tensiunea, ritmul, densitatea și forma. Nodul pare să audă, nu să danseze.

RMSVolum → amplitudine și respirație.
CENTROIDBrilliance → asperitate / număr de lobi.
FLUXSchimbare → impuls și propagare în tendrils.
05

Tool, not product

Suprafața trebuie să pară că poate fi învățată și stăpânită. Mai aproape de norns, VCV Rack și terminal decât de o aplicație de productivitate cu onboarding.

USEKeyboard-first, shortcuts vizibile, command layer, output direct.
SHOWStarea sistemului, conexiunile și consecința acțiunii.
NEVERConfetti, streaks, badges motivaționale sau coach tone.

06

Data brutalism

Informația poate deveni densă și severă, dar trebuie să rămână diagnostică. Ryoji Ikeda, FIELD și onformative oferă ritm, nu template.

USEScanlines, counters, sparse micro-accent, kinetic type.
MUTATETaskurile și memory links devin semnale cu frecvențe distincte.
NEVERData-viz falsă care nu corespunde niciunei stări reale.
07

Typographic voice

Display-ul are personalitate și sarcasm. Body-ul mono rămâne exact, rece și ușor de scanat. Nici Inter, nici „startup friendliness”.

PAIR ABasteleur × Departure Mono. Basteleur = display occult-machine (tarot, medieval × Cooper Black). Departure Mono = labels, timestamps, system text (pixelat, lo-fi tehnic).
PAIR BAvara × Fragment Mono. Avara = serif editorial ascuțit pentru titluri/pull-quotes. Fragment Mono = body/mono cu căldură pentru knowledge text.
ACCENTPilowlava doar pentru wordmark/chapter art. Niciodată mai mult de două familii display.

Build paths

Trei niveluri de implementare. Recomandarea pragmatică este să începi cu 2D organic și să escaladezi shader-ele doar unde produc valoare vizibilă.

PATH A / LOW RISK

Organic 2D

Cel mai bun punct de start pentru un graph dens, interactiv și performant.

  1. PixiJS — render 2D/WebGL
  2. d3-force — physics only
  3. simplex-noise — node contours
  4. Motion — UI shell feedback
  5. CSS/SVG grain + dither assets
PATH B / FULL ORGANISM

Shader field

Pentru selected clusters, hero states și forme care se contopesc real.

  1. React Three Fiber / Three.js
  2. GLSL SDF + smooth-min metaballs
  3. LYGIA noise functions
  4. Meyda / Web Audio mappings
  5. GSAP timeline for cascade
PATH C / R&D LAB

Prototype first

Explorare foarte rapidă înainte de a bloca arhitectura web.

  1. Sketch Design Club / references
  2. Hydra — feedback & modulation
  3. Shader Park — SDF forms
  4. TouchDesigner / Max — mappings
  5. Port only the winning grammar
05

Kill list

Acestea sunt semnale de drift. Dacă apar în mockup, direcția a revenit la productivitate SaaS standard.

×Glassmorphism

Fără blur, translucent cards, glow borders sau pseudo-depth corporate.

×Uniform radius

Nu toate lucrurile au aceeași cutie, aceeași rază și aceeași umbră.

×Inter / Poppins

Nicio neutralitate startup. Display expresiv + mono tehnic.

×Circle graph

Nodurile sunt membrane, nu avatar circles; conexiunile sunt tendrils, nu straight lines.

×Streak economy

Fără confetti, daily flames, badges și guilt loops mascate în gamification.

×Calm AI helper

Goblin-ul nu „celebrează progresul”. Observă, taie, amintește și provoacă.

×Obsidian clone

Nu un force graph decorativ de cercuri. Relațiile trebuie să aibă greutate și viață.

×Dashboard wall

Nu 12 KPI cards. Un câmp cognitiv cu un lucru dominant și stări contextuale.

×Permanent motion

Mișcare doar când semnifică activitate, tensiune, decay sau feedback.
